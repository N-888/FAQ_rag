## О проекте

**FAQ RAG** — это интеллектуальная система для работы с базой знаний компании. Пользователь задаёт вопрос, система ищет релевантные фрагменты в загруженных документах и формирует точный ответ.

### Преимущества

- **Точность** — ответы основаны на реальных документах, а не на выдумках модели
- **Простота** — визуальная сборка сценариев в n8n, без программирования
- **Масштабируемость** — легко добавлять новые документы и расширять функционал
- **Безопасность** — данные хранятся в вашем облаке, не уходят на сторонние серверы

## Как это работает

```
Пользователь → Вопрос → Эмбеддинг → Поиск в Qdrant → Контекст → LLM → Ответ
```

### Этап 1: Загрузка документов

1. Текст документа разбивается на фрагменты (чанки) по 500 символов
2. Каждый фрагмент превращается в числовой вектор (эмбеддинг)
3. Векторы сохраняются в векторную базу Qdrant

### Этап 2: Обработка вопросов

1. Вопрос пользователя превращается в вектор
2. Система ищет 4 наиболее релевантных фрагмента
3. Найденные фрагменты передаются языковой модели
4. Модель формирует ответ на основе найденной информации

## Архитектура

### Ветка 1: Загрузка документов

```
Manual Trigger
     ↓
Получить токен GigaChat
     ↓
Документ (текст FAQ)
     ↓
Нарезка на чанки (500 символов, перекрытие 50)
     ↓
Добавить токен к чанкам
     ↓
Создать эмбеддинг (GigaChat Embeddings)
     ↓
Собрать точки (вектор + текст)
     ↓
Отправить в Qdrant
```

### Ветка 2: Обработка вопросов

```
Chat Trigger
     ↓
Токен GigaChat
     ↓
Подготовка (вопрос + токен)
     ↓
Эмбеддинг вопроса
     ↓
Собрать запрос
     ↓
Поиск в Qdrant (top 4)
     ↓
Подготовить контекст
     ↓
Merge
     ↓
LLM (Qwen/YandexGPT)
```

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/N-888/FAQ_rag.git
cd FAQ_rag
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и заполните реальными значениями:

```bash
cp .env.example .env
```

| Переменная | Описание | Где получить |
|-----------|----------|--------------|
| `GIGACHAT_AUTH_KEY` | Ключ авторизации GigaChat | [developers.sber.ru](https://developers.sber.ru/portal/products/gigachat) |
| `QDRANT_ENDPOINT` | Адрес кластера Qdrant | [cloud.qdrant.io](https://cloud.qdrant.io) |
| `QDRANT_COLLECTION` | Название коллекции | `faq_documents` |
| `QDRANT_API_KEY` | API-ключ Qdrant | Интерфейс Qdrant |

### 4. Настройка Qdrant

1. Зарегистрируйтесь на [cloud.qdrant.io](https://cloud.qdrant.io)
2. Создайте бесплатный кластер
3. Создайте коллекцию:
   - Название: `faq_documents`
   - Размер вектора: `2056`
   - Метрика: `Cosine`

### 5. Настройка n8n

1. Откройте n8n
2. Перейдите в **Settings** → **Environment Variables**
3. Добавьте переменные из `.env` файла
4. Импортируйте файл `RAG_n8n_workflow.json`

### 6. Запуск

1. Запустите ветку **Manual Trigger** для загрузки документов
2. Дождитесь завершения (все ноды зелёные)
3. Запустите ветку **Chat Trigger**
4. Задайте вопрос в чате
