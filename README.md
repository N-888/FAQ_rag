---

## О проекте

**FAQ RAG** — это интеллектуальная система для работы с базой знаний компании Sun Rent (аренда автомобилей в Испании). Пользователь задаёт вопрос через URL, система ищет релевантные фрагменты в загруженных документах и формирует точный ответ с помощью GigaChat.

---

## Как это работает

```
Пользователь → Webhook (URL) → Поиск в Qdrant → Контекст → GigaChat LLM → Ответ
```

### Ветка 1: Загрузка документов

1. Текст документа разбивается на фрагменты (чанки) по 500 символов
2. Каждый фрагмент кодируется в числовой вектор (char-based хеш, размер 256)
3. Векторы сохраняются в векторную базу Qdrant

### Ветка 2: Обработка вопросов

1. Вопрос пользователя поступает через Webhook (GET-запрос)
2. Все документы загружаются из Qdrant (scroll)
3. Система ищет наиболее релевантные фрагменты по ключевым словам
4. Найденный контекст передается в GigaChat-2
5. Модель формирует ответ на основе найденной информации

## Архитектура

### Ветка 1: Загрузка документов

```
Manual Trigger
     ↓
Документ (текст FAQ)
     ↓
Нарезка на чанки (500 символов, перекрытие 50)
     ↓
Создать эмбеддинг (char-based hash, размер 256)
     ↓
Отправить в Qdrant (PUT)
```

### Ветка 2: Обработка вопросов

```
Webhook (GET /webhook/rag-question?query=...)
     ↓
Подготовка (извлечение query)
     ↓
Получить документы из Qdrant (scroll)
     ↓
Поиск по тексту (keyword matching)
     ↓
Если найдено → GigaChat LLM → Ответ Webhook
Если не найдено → "К сожалению..."
```

## Технологии

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Оркестрация | n8n 2.32.6 | Визуальная сборка и автоматизация сценариев |

| Авторизация | GigaChat OAuth | Получение токенов для работы с API |

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/N-888/FAQ_rag.git
cd FAQ_rag
```

### 2. Настройка переменных окружения

| Переменная | Описание | Где получить |
|-----------|----------|--------------|
| `GIGACHAT_AUTH_KEY` | Ключ авторизации GigaChat | [developers.sber.ru](https://developers.sber.ru/portal/products/gigachat) |
| `QDRANT_ENDPOINT` | Адрес кластера Qdrant | [cloud.qdrant.io](https://cloud.qdrant.io) |
| `QDRANT_COLLECTION` | Название коллекции | `faq_documents` |
| `QDRANT_API_KEY` | API-ключ Qdrant | Интерфейс Qdrant |

### 3. Настройка Qdrant

1. Зарегистрируйтесь на [cloud.qdrant.io](https://cloud.qdrant.io)
2. Создайте бесплатный кластер
3. Создайте коллекцию:
   - Название: `faq_documents`
   - Размер вектора: `256`
   - Метрика: `Cosine`

### 4. Настройка n8n

1. Запустите n8n в Docker
2. Импортируйте файл `RAG_n8n_workflow.json`

### 5. Запуск

1. Откройте n8n и найдите сценарий «RAG-помощник по документам»
2. Нажмите **Manual Trigger** → **Execute workflow** для загрузки документов
3. Дождитесь завершения (все ноды зелёные)
4. Откройте в браузере:
   ```
   http://localhost:5678/webhook/rag-question?query=Какие%20условия%20аренды
   ```
